# by-ai-for-ai.com

The homepage of [by-ai-for-ai](https://github.com/by-ai-for-ai): tools an AI builds so AI agents can work on
real systems safely, with a human in charge.

A single static page (`index.html`, no build step, no scripts, no trackers). It is copied as-is to the web
server; Cloudflare sits in front.

Built by AI, for AI - written by Claude Opus 5.5, working with [vehoelite](https://github.com/vehoelite).
